Windows SmartScreen
이 파일은 코드 서명되지 않은 개인 베타 프로그램이므로 SmartScreen 경고가 표시될 수 있습니다. 파일 출처를 확인한 뒤 Windows 경고 창의 '추가 정보'에서 게시자와 파일명을 확인하고 실행 여부를 직접 결정하세요. Windows 보안 기능을 끌 필요는 없습니다.

로그 위치
%LOCALAPPDATA%\MusicWaveStudio\logs\music_wave_studio.log
로그에는 버전, OS, renderer, preset, 입력 개수, export profile 및 오류 정보만 기록하며 음원 내용은 기록하지 않습니다.
