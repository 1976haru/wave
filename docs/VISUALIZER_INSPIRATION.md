# Visualizer inspiration

Music Wave Studio v0.7.8의 기본 프리셋은 bars, mirror bars, line, ribbon, dots, ring, radial, pulse, meter 같은 일반적인 오디오 시각화 개념을 독자적으로 조합한 것입니다.

참고한 공개 프로젝트:

- CaYatur/SoundVisualizer — spectrum/bar 구성 아이디어
- stefanbocane/Audio-Visualizer- — minimal line과 glow 배치 참고
- Naresh-Cod/python-realtime-audio-visualizer — 실시간 반응 구조 참고
- kultyapka3/pyqt5-spectrogram — 스펙트럼 시각화 UI 참고
- Lorakszak/wavern — 시각적 개념만 참고

외부 프로젝트의 소스 코드를 복사하거나 파생한 코드는 포함하지 않았습니다. 특히 Wavern은 GPLv3 프로젝트이므로 콘셉트만 참고했으며 코드와 리소스를 복사하지 않았습니다. 각 preset JSON과 thumbnail은 Music Wave Studio에서 새로 작성·생성합니다.
